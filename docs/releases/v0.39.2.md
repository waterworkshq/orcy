# v0.39.2 — Patch: Extraction rerun concurrency proof + lint and test fixture cleanup

A test-hardening and code-quality patch. No behavior changes in production code.

## Concurrency proof for fresh-rerun allocation

Adds a multi-process test that spawns worker processes competing to allocate fresh extraction reruns simultaneously. The test proves that the allocation path produces monotonic generation numbers with no collisions and no lock timeouts under genuine concurrency, not just under in-process mock parallelism.

## Lint and test fixture fixes

Removes unused identifiers and fixes error-cause forwarding flagged by the linter across the API and UI packages. Corrects mocked error fixtures in the prioritization test suite and a missing remote-participant fixture in the board-summary test suite — both caused intermittent test failures when assertions exercised the error path.
