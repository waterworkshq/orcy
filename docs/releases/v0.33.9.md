## Summary

A small internal-correctness + coverage patch. No schema migrations, no breaking changes, no operator-facing behavior change.

1. **Task-creation governance fingerprint honesty.** The prospective-governance freeze captured the freeze-time interceptor-quarantine flag as a hardcoded `false`, so the enrollment/governance fingerprint was untruthful about the admission state it was evaluated against. The flag is now populated truthfully from the live quarantine state, so decision-reuse dedup is honest across quarantine-state changes. It is a no-op unless an interceptor is quarantined (rare); the runtime remains authoritative on quarantine for invocation gating, and the per-batch quarantine-freeze behavior is unchanged and documented.
2. **Import scoped-delete production-DB test.** The import orchestrator's scoped-delete (explicit child-entity deletes in reversed manifest-domain order) was exercised only on the test DB driver, where foreign-key / cascade enforcement is unreliable. A new integration test runs it on the production driver (`PRAGMA foreign_keys = ON`) against a full habitat tree, confirming the explicit deletes + `ON DELETE CASCADE` coexist with **no FK violation** and the reversed-domain order honors the `missions.columnId → columns` NO ACTION constraint (missions deleted before columns). Test-only; no behavior change.
3. **Commit-message convention.** `CONTRIBUTING.md` now forbids internal ticket/candidate tags anywhere in commit/PR messages (subject and body) — they leak into the auto-generated changelog and add noise. Contributor docs only.
