# v0.39.1 — Patch: Comment pagination and query error retry on the communication board

The mission communication board previously loaded a single page of comments with no error recovery. Long threads were truncated, and any query failure silently left the board in a loading state with no recourse.

## Comment pagination

The comments feed now uses an infinite-query hook (`useMissionCommentsFeed`) that loads additional pages as the user scrolls. The `MergedFeed` component surfaces a "Load more" affordance when more pages are available and shows a compact loading indicator during fetches. The existing pulse feed hook is updated to align with the paginated query lifecycle.

## Query error retry

When a comment or pulse query fails, the board now surfaces the error state with a retry button instead of silently hanging. The `MissionCommunicationBoard` component handles three query states — loading, error, and success — each with appropriate UI: a spinner during initial load, a retry card on error, and the merged feed on success.
