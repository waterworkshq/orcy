# v0.39.6 — Patch: Strict automation rule draft typing and route validation schemas

Automation rule create/update routes accepted arbitrary JSON for triggers and actions (`z.object({}).passthrough()`), meaning malformed rules could pass validation and fail at runtime. This patch replaces the passthrough schemas with strict discriminated unions and exports shared types so that rule drafts are machine-readable across UI, API, and recommendation sources.

## What changed

- **Shared type exports** (`@orcy/shared`): the inline `AutomationEventType`, `AutomationScanType`, and `AutomationActionType` unions are now backed by exported `as const` arrays (`AUTOMATION_EVENT_TYPES`, `AUTOMATION_SCAN_TYPES`, `AUTOMATION_ACTION_TYPES`), enabling runtime validation downstream. New `AutomationRuleDraft` interface provides a machine-readable authoring contract for rule drafts.

- **Strict Zod schemas** (`packages/api/src/models/automationRuleSchema.ts`): new module with discriminated unions for triggers (`event` vs `scan`), actions (`notify`, `create_signal`, `create_task`, `change_priority`, `assign`, `release_assignment`, `request_review`, `call_webhook`, `mark_risk`, `plugin`), and recipients. The `createAutomationRuleSchema` and `updateAutomationRuleSchema` enforce field-level constraints (min/max lengths, required nested objects, URL validation on webhooks).

- **Route validation** (`packages/api/src/routes/automationRules.ts`): the inline passthrough `createRuleSchema` and `updateRuleSchema` are replaced with imports of the strict schemas. Routes now reject malformed triggers and actions at the boundary instead of deferring failures to rule execution time.

## Verification

- `@orcy/shared` build: clean.
- `@orcy/api` typecheck: clean.
- `@orcy/api` tests: 15 passed in `automationRuleDraftValidation.test.ts`.

## No operator action required

No schema changes, no migrations. Existing valid rules continue to validate against the stricter schemas; previously-accepted malformed payloads will now be rejected at the API boundary.
